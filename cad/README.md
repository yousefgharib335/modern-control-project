# CAD inputs

Place new supplied files in the project's `resources/` folder for review. Reviewed CAD can then be organized under `cad/`, retaining assembly and part references.

The [Inventor source package](originals/modern%20control/) is stored with its supplied folder structure. See the [CAD review](../documentation/cad-review.md) for assembly references and extracted mass properties.

This folder also contains the alloy-steel pendulum conversion and the [Simscape exports](simscape-exports/).

Record material assignments, units, center of mass, inertia tensor, and joint axes for the new design. Keep converted geometry in a separate folder from supplied originals.
