# Generated outputs

Running `verify_dashboard` regenerates the [dashboard preview](../dashboard/output/dashboard_preview.png) and the [verification CSV](../dashboard/output/dashboard_test.csv) from synthetic input. MATLAB prints the verification result in the Command Window. The [saved MATLAB log](../dashboard/output/dashboard_test.log) records a previous run.

The `.gitkeep` files mark the output directories so they can be retained when generated files are absent.
